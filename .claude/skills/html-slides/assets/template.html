· Error común

Asignar una lista no la copia: la comparte

Lo que parece

b = a crea otra lista

Cambiar b dejaría a intacta.

Lo que pasa

Dos nombres, una lista

Ambos apuntan al mismo objeto; para copiar usa a.copy().

  • Conecta con la slide de predicción: quien votó A sostenía el mito.
  • Pregunta de cierre: ¿cómo lo comprobarías con id()?
