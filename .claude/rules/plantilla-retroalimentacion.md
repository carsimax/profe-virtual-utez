# Plantilla: retroalimentación

1. Fortaleza concreta.
2. Brecha respecto al criterio.
3. Siguiente paso accionable.
4. Nivel alcanzado.

Tono respetuoso y específico, sin juicios personales. Máximo 120 palabras salvo que se pida más.
